# Gym-management-system
Gym membership and sports equipment management system for SLIIT

## Running

- **Backend (Spring Boot, port 8801):** `./mvnw spring-boot:run`, or run `GymManagementApplication` in IntelliJ.
- **Frontend (React, port 5173):** `cd frontend && npm install && npm run dev`, then open http://localhost:5173. See [frontend/README.md](frontend/README.md).
